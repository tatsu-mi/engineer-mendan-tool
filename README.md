# engineer-mendan-tool（面談練習ツール）

SES技術者向けに、AIとの音声面談を練習するツールです。

## 面談の準備

1. Microsoftの社員アカウントでログインします。
2. 「接続設定」にGoogle AI Studio APIキーを入力します。キーは保存されないため、利用時に入力してください。
3. スキルシートを直接入力するか、PDF（4MBまで）から取り込みます。Excelには対応していません。
4. 案件情報を入力します。「スキルシートから案件を生成」を使う場合は、マッチ度を「高・中・低」から選び、生成後の内容を確認・編集します。
5. 主質問数（1〜20問）と回答の深掘りを設定します。
6. 必要に応じて録音・録画を選択し、「面談を開始」を押します。ブラウザのマイク利用を許可してください。

## 面談の進め方

1. AIによる案件説明を聞き、自己紹介と案件に関連する質問に回答します。
2. 主質問に音声で回答し、回答後に「回答を送信して次へ」を押します。
3. 最後に逆質問を行います。質問を終えるときは「もう質問はありません」と伝えてください。

自己紹介・案件に関連する最初の質問・深掘り・逆質問は、設定した主質問数に含みません。途中で終える場合や自動で終了しない場合は「面談を終了」を押します。

接続が途切れた場合は、面談画面または本人の履歴詳細から「途中から再開」を選び、APIキーを再入力してください。保存済みの会話・進捗から再開します。保存前の音声は復元できません。

## 録音・録画と話し方の評価

開始・再開前に「音声のみ」または「音声＋カメラ映像」を選ぶと、自分とAIの音声を記録できます。初期設定は「記録しない」です。録画にはカメラの利用許可が必要です。

終了・中断後、ページを閉じる・再読み込みする前に記録ファイルをダウンロードしてください。ファイルはブラウザ内だけに保持され、サーバーには保存されません。再開時は別ファイルになります。長時間の記録は端末のメモリを使用します。

「録音・録画から話し方・振る舞いを評価する」を有効にすると、回答の一部を面談終了時にGoogle Geminiへ送信し、話し方や、カメラ使用時の身振り・表情・姿勢への助言を総評に追加します。追加のAPI利用料が発生します。解析対象は回答冒頭の最大12秒×先着8区間（合計1.5MB以内）で、再読み込みすると解析用区間は失われます。

## 総評・履歴の確認

面談後は総評で評価と改善アドバイスを確認できます。評価は会話で確認できた内容を根拠とし、総合5点＝◎、4点＝○、3点＝△、1〜2点＝×で表示します。

過去の面談は「面談履歴」から確認できます。完了・中断した面談の履歴詳細で「会話ログから再評価」を選び、APIキーを入力すると、現在の採点基準で総評を上書きします。候補者の発言がある会話ログが必要です。音声・動画は再解析せず、既存の助言を保持します。

## 管理者の使い方

管理者は閲覧可能な他メンバーの面談も再評価できます。

メニューまたはヘッダーの「利用分析」から、期間別・メンバー別の面談回数、完了率、面談時間、利用日数を確認できます。

- 期間は今月・先月・直近30日・任意期間から選択します。日付は日本時間の面談開始日が基準です。
- 「管理者を除外する」を選ぶと、利用停止中を含む管理者を集計から除外します。
- 各データ列の見出しをクリックすると、昇順・降順を切り替えられます。
- 登録済みの有効なメンバーが対象で、期間内に未利用のメンバーも表示します。初回ログイン前の社員は含みません。
- 最終面談日時とリンク先の履歴は全期間、合計・平均時間は完了・中断して時間が保存された面談が対象です。

環境構築・認証・DB設定・デプロイの手順は[セットアップガイド](./docs/setup.md)を参照してください。
